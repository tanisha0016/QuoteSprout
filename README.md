# QuoteSprout - Quote of the Day

QuoteSprout is a simple web application that fetches and displays a random quote each time a user clicks the "New Quote" button. The application also allows users to tweet the current quote with a click of a button.

## Features

- **Fetch Random Quotes**: Retrieve a new quote from the Quotable API with each click on the "New Quote" button.
- **Share on Twitter**: Easily share the current quote on Twitter using the "Tweet" button.
- **Responsive Design**: The application is designed to be visually appealing and functional across various devices.

## File Structure
The project includes the following key files:

- **index.html**: The main HTML file that provides the structure for the web page.
- **script.js**: Contains the JavaScript code to fetch quotes and handle interactions.
- **style.css**: Provides styling for the application.
- **twitter.jpg**: An image used for the tweet button.

## Usage
Get a New Quote: Click the "New Quote" button to fetch a new quote from the Quotable API.
Tweet the Quote: Click the "Tweet" button to share the current quote on Twitter.
